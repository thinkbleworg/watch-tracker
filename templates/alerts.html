How notification delivery works

The tracker creates an alert record before attempting Telegram delivery. A successful Telegram response changes the record to sent.

If delivery fails, the alert remains available as failed so it can be retried later. Pending alerts can also be retried after an interrupted application run.

The first catalogue-seeding run is silent, so existing watches do not generate a Telegram flood.
